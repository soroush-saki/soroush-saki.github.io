# Soroush Saki — Portfolio

A static, portable copy of the supplied portfolio. Original section layout, imagery, typography, content, hash navigation, and animations are retained. Malformed GitHub and mailto links are corrected. No build tools or server required.

## GitHub Pages

1. Create a repository in your GitHub account (or use an existing one). For a personal root site, name it `soroush-saki.github.io` if your username is `soroush-saki`.
2. Upload the **extracted files in this ZIP** into the repository root: `index.html`, `.nojekyll`, `assets/`, `fonts/`, and `fonts.css`. Keep all folders and filenames intact. Git push preserves the complete folder structure.
3. In the repository, open **Settings → Pages**. Choose **Deploy from a branch**, then **main** and **/(root)**, and save.
4. GitHub shows the published URL in that Pages screen when deployment completes.

This ZIP is ready to upload at the repository root. No build step is required.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Editing and local preview

Edit `index.html` for text, links, styles, and interactions. Image assets are in `assets/images/`. Serve the extracted directory using any static web server.

Twitter has no destination in the original and retains its original behavior. Existing article, project, and certificate links are preserved; their third-party destinations have not been independently audited.
